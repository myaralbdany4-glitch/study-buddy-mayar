
# Study Buddy

## Purpose
Study Buddy is a simple Python project that helps students manage their study tasks.

## How to run
Run buddy.py using Python or Google Colab.

## How to contribute
Create a branch, make changes, and open a Pull Request for review.

## Out of scope
Notifications, databases, and user accounts are not included.

## Team & Access
- Admin: Manages the repository and settings.
- Write: Can edit code and contribute.
- Read: Can view and review the project.
